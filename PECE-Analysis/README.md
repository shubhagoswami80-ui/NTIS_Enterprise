# NTIS Evidence Fusion V2.4 — Controlled Interaction Evidence

V2.4 extends the validated V2.3 forward-outcome layer into a controlled
interaction study.

Tested 2-way families:
MWPL×Futures, MWPL×Buildup, MWPL×PCR Change, MWPL×Volume,
Futures×Buildup, Futures×PCR Change, Futures×Volume,
Buildup×PCR Change, Buildup×Volume, PCR Change×Volume.

Tested 3-way families:
MWPL×Futures×Volume, MWPL×Futures×PCR Change,
MWPL×Buildup×Volume, MWPL×Buildup×PCR Change,
Futures×Buildup×Volume, Futures×Buildup×PCR Change,
Futures×PCR Change×Volume, Buildup×PCR Change×Volume.

No unrestricted combinatorial search is used.
Minimum pooled sample: 200 observations.
Minimum per-day sample for day-stability detail: 50 observations.

Forward outcome:
same symbol/session, first actual observation at or after 5/15/30/60 minutes.

This is research/discovery only and does not establish a trading rule.
