# Operator Control

Preferred single script:

`SDL\derivative_signal\scripts\derivative_signal.ps1`

Commands:

```powershell
.\derivative_signal.ps1 start
.\derivative_signal.ps1 stop
.\derivative_signal.ps1 restart
.\derivative_signal.ps1 status
```

Port 8505 only.

The existing SDL on port 8504 is intentionally outside the scope of this script.
