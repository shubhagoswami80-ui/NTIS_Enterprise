# PE/CE XHR Downloader — Phase 1

This is an isolated diagnostic phase for the new iCharts PE/CE downloader.

## Frozen existing pipeline

Do NOT change:
- `ReportGenration/app.py`
- `ReportGenration/reports.json`
- `ReportGenration/browser_profile`
- existing six report jobs, selectors, destinations, and naming rules

## Purpose

Capture the actual iCharts XHR/fetch request generated by the PE/CE page.
The response body is retained so the exact schema can be inspected before
writing the production collector.

## Run

From `ReportGenration`:

```powershell
python pece_xhr_probe.py --url "<PE/CE iCharts page URL>"
```

If the page needs a manual action, perform it in the opened Chromium window.
The probe does not download Excel files and does not alter the existing
downloader configuration.

Output is created below:

`ReportGenration/pece_xhr_probe/<timestamp>/`

Files:
- `manifest.json`
- `response_0000.txt`, etc.

After the exact endpoint, request method, parameters and response schema are
verified, Phase 2 can implement the isolated production collector.
